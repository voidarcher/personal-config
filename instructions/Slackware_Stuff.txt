Slackware Stuff
---------------
The best advice: pursue Slack.
Do the Full Installation. Don’t install anything. Don’t do any weird 
configurations. Just install Slackware, upgrade the system with slackpkg, 
customize KDE, make your config files, and forget about it. Check the 
changelog every night, and slackpkg up* when you need to. If something 
doesn’t upgrade with slackpkg, just don’t worry about it. Actually be a 
Slacker about things and pursue Slack.

Remember that Pat Volkerding won't be around forever, and probably
neither will this distribution. You have a limited time on Earth to be a
Slacker, so make it good.

Installing GRUB instead of ELILO:
---------------------------------
Skip installing LILO and ELILO
Finish the installation
Go into "Shell" instead of "Reboot"

First, chroot into the new system

# chroot /mnt /bin/bash

Then, source profile

# source /etc/profile

Then, actually install GRUB

# grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=Slackware

Then, create the GRUB configuration file

# grub-mkconfig -o /boot/grub/grub.cfg

For setting a background, you move the file into

/boot/grub/themes/floating_gnu_grub_background.png

(Really gotta shorten that name)

Then, add this to /etc/default/grub:

GRUB_BACKGROUND="/boot/grub/themes/floating_gnu_grub_background.png"

Creating a user:
----------------
(As root user once you've rebooted into your system)

# useradd -m -g users -G 
    wheel,floppy,audio,video,cdrom,plugdev,power,netdev,lp,scanner 
    -s /bin/bash username

# passwd username

Go into /etc/inittab and set runlevel from 3 to 4


Setting up Slackpkg:
--------------------
(As root user)

First, uncomment a mirror

# vim /etc/slackpkg/mirrors

Then, initialize the database

# slackpkg update gpg

Then, do the regular update process

# slackpkg update
# slackpkg install-new
# slackpkg upgrade-all
# slackpkg clean-system

Installing a SlackBuild:
------------------------
Download the SlackBuild tarball to your ~/SlackBuilds
directory. Unpack it:

$ tar xvf fastfetch.tar.gz (Just using fastfetch as an example)

Then, cd into the created directory. Then, download the source code
from the SlackBuilds page. Tbh I've just done this graphically instead
of using wget.

Anyway, now you should have everything you need in your ~/SlackBuilds/fastfetch
directory. cd into it and run:

$ su -l (You'll need a proper login shell)

As root, install the SlackBuild:

# chmod +x fastfetch.SlackBuild 
# ./fastfetch.SlackBuild

Now, there should be an installable tarball in /tmp. Go there and:

[In /tmp]
# installpkg fastfetch-x-y-z.txz

Aaaaand you're done!

Now, remove the stuff in /tmp you no longer need:

[In /tmp]
# rm -r Sbo
# rm fastfech-x-y-z.txz

I don't know how old you are when you're reading this again, but I'm sure you can
remember/figure out how to delete old files. Basically, there's a package record in
/var/log/packages/. Grep it to find the name of the package you're trying to uninstall.
Then, just run removepkg:

# removepkg fastfetch-2.66.1-x86_64-1_SBo

Then, you'll have to remove any config files in ~/ yourself. Hopefully, you already
removed the stuff in /tmp, but if not, check there too.

For upgrading, it's just the installation process, but you run

# upgradepkg fastfetch-x-y-z.txz 

instead of installpkg.

Good luck, Slacker.
