OpenVPN HOWTO
-------------
Ignore everything below the dotted line and just use WireGuard instead. It
is legitimately more usable than even the ProtonVPN GUI app, as long as
you're trying to use the same VPN location. 

$ nmcli connection import type wireguard file /path/to/wg.conf

After this, it should just be in NetworkManager. Remember to set it to not
autostart on boot. But yeah, that's it. Works perfectly.




--------------------------------------------------------------------------

1)  OpenVPN should already be installed on Slackware-current (the one
    that will eventually become Slackware 15.1 or 16.0).

2)  Download whatever config file you want from account.protonvpn.com/downloads.
    Make sure it's a UDP, GNU/Linux option.

3)  Set up:
    
    a) The proton directory in your openvpn directory
    b) Your credentials file, which will hold your OpenVPN Proton
       login and passphrase

4)  In the VPN config file, modify:
    
    # auth-user-pass /path/to/credentials

5)  You might also have to comment out whatever is under "script-security 2"

6)  Don't forget to 
    # chmod 600 /path/to/credentials

7)  Download the vpn_start script, make it executable, and move it to /usr/local/bin
